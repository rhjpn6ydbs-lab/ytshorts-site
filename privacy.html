Privacy policy

ytshorts-tools is a personal tool used only by its owner. It has no other users.

What it accesses

With the owner's permission, it reads analytics and basic details for the owner's own YouTube channels, and uploads videos to those channels, using Google's YouTube Data API and YouTube Analytics API.

How the data is used and stored

The data is used only to show the owner how their own videos perform and to publish the owner's own videos. It is stored only in the owner's private files and is not shared with anyone, sold, or used for advertising.

ytshorts-tools's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke access at any time at myaccount.google.com/permissions.
